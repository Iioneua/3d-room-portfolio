# 3D Room Portfolio

A personal website presented as a cozy, low-poly isometric 3D room. Each corner of the room holds an object that represents a social profile or a piece of information about me. Clicking a corner flies the camera to that object, and the object itself displays the content and links.

## Planned features

- Cozy low-poly isometric room with calm colors, built in code from simple shapes
- A dev and designer desk setup as the centerpiece
- Click-to-fly camera navigation between corners, with a way back to the overview
- Window view of a sunset by the sea, with ambient nature sounds
- Lightweight, so it loads well on ordinary computers
- Desktop first, English only (for now)
